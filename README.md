# Legends

Full-stack app with a Spring Boot backend and a Vite/React frontend.

## Frontend

Install dependencies from the repository root:

```sh
npm install
```

Run common frontend tasks from the repository root:

```sh
npm run dev
npm run build
npm run lint
npm run preview
```

Dependencies are installed in the root `node_modules` directory. The frontend source remains in `frontend/`.

## Backend

Run backend tests from `backend/`:

```sh
.\mvnw.cmd test
```

The backend source remains in `backend/`.
