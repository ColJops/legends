# Map data attribution

`poland-voivodeships.geojson` contains simplified voivodeship boundaries from [polska-geojson](https://github.com/ppatrzyk/polska-geojson), by Piotr Patrzyk. The project identifies GUGiK as a source of the underlying geographic data. The GeoJSON is distributed under the MIT License; see `POLSKA-GEOJSON-LICENSE.txt`.

The map page displays a source link next to the visualization.
